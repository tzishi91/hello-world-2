# hello-world-2

A simple to-do application to keep track of tasks across multiple projects.

## Features

- **Multiple projects** – create as many projects as you need and switch between them
- **Add tasks** – type a task and press *Add Task* or hit Enter
- **Tick off tasks** – check the checkbox next to a task to mark it as done
- **Delete tasks** – remove individual tasks with the × button
- **Delete projects** – remove an entire project and all its tasks
- **Persistent storage** – tasks and projects are saved in the browser's `localStorage`

## Usage

Open `index.html` in any modern web browser – no build step or server required.
